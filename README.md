🎥 AI Video Agent

Live Demo: https://ai-agent-gamma-beryl.vercel.app

An AI-powered toolkit that helps creators analyze, enhance, and optimize video content. Built with Next.js and designed to supercharge your creative workflow using advanced AI tools.

🚀 Features
🔍 AI Analysis

Get deep insights into your video content using advanced AI. Understand viewer engagement, pacing, structure, and overall content quality.

✍️ Smart Transcription

Generate accurate transcripts for your videos — perfect for subtitles, blog posts, accessibility, or repurposing your content.

🖼️ Thumbnail Generation

Create eye-catching, AI-generated thumbnails to boost click-through rates with compelling visuals.

📝 Title Generation

Generate attention-grabbing, SEO-optimized titles tailored to your content and audience.

🎬 Shot Script

Receive detailed, step-by-step instructions to recreate viral videos. Learn camera angles, shooting techniques, and editing approaches used by top creators.

🤖 Discuss With Your AI Agent

Chat with your AI agent about content strategy, new ideas, audience growth, and more.

🛠️ Getting Started

First, install dependencies and run the development server:

npm install
npm run dev
# or
yarn install
yarn dev
# or
pnpm install
pnpm dev
# or
bun install
bun dev


Then open http://localhost:3000
 in your browser.

Start editing by modifying app/page.tsx. Changes are applied instantly thanks to hot reloading.

This project also uses next/font to automatically load and optimize the Geist font by Vercel.
